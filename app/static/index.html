A tiny model that learned SQL from a score, not from answers.

A 0.5-billion-parameter model was trained with reinforcement learning (GRPO). It was never shown a correct query: it wrote several attempts, each was run on a real database, and it was told only whether the rows were right. Ask a question and compare it with its untrained self and a frontier model.

    How it works
    
  
    GRPO (Group Relative Policy Optimization) is the reinforcement-learning method behind DeepSeek-R1. The training loop here is written from scratch in PyTorch, about 150 lines, and ran on a laptop.
    
  
      
    
    1. Sample a groupFor each question the model writes 8 different queries by sampling.
      2. 
    
    2. Check, don't judgeEach query is run on the database. Right rows with the columns the question asks for: reward 1. Runs but wrong: 0.2. Fails: 0.
      3. 
    
    3. Compare inside the groupEach attempt's advantage is its reward minus the group average, divided by the spread. No extra "critic" network.
      4. 
    
    4. Nudge the modelTokens of better-than-average attempts become more likely, the others less. Only a small LoRA adapter is trained.
